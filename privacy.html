Privacy Policy — Household Agent

Effective date: September 13, 2026

Household Agent ("the App") is a local-first household-orchestration prototype. This policy describes what data the App processes when you interact with it, including via the WhatsApp Cloud API integration.

1. Data we process

  • WhatsApp phone number and message content: when you message the App's WhatsApp number, Meta delivers your phone number (WhatsApp user ID) and message text to our webhook so we can reply.
  • Household data you enter: inventory, dishes, preferences, and schedules you provide through the App, stored in a local SQLite database.

2. How we use it

  • To generate a reply to your WhatsApp message using a locally hosted language model (Ollama). Message text is used only to produce the reply.
  • To operate household features you explicitly use (meal plans, inventory, scheduling).

3. What we do not do

  • We do not sell, rent, or share your personal data with third parties for marketing or advertising.
  • We do not use your messages for any purpose other than replying and operating the features you request.

4. Storage and retention

Household data is stored locally in the App's SQLite database. WhatsApp message IDs are kept in short-lived server memory solely to ignore duplicate deliveries from Meta. Message content is not retained beyond what is needed to reply, unless you explicitly save resulting data (e.g. inventory entries) through the App.

5. Meta's processing

WhatsApp messages transit Meta's WhatsApp Cloud API, which applies Meta's own privacy policy. We have no control over Meta's handling of data on its systems.

6. Your choices

Stop messaging the App's WhatsApp number at any time to stop further WhatsApp processing. To request deletion of stored household data, contact us below.
